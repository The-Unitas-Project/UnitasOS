# Project instructions

Use ASD-STE100 for all comments, documentation, and docstrings.

Write for programmers who know C and basic systems concepts. Use short, direct sentences. Prefer active voice and common words. Explain an acronym when readers need its meaning. State contracts, ownership, limits, and hardware requirements. Do not explain an obvious line of code.

Do not wrap prose at a fixed column width. Keep source and configuration syntax valid.
